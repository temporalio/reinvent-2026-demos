# AgentCore On-Call

Replace the research placeholder with the upstream on-call agent. Keep the existing station key so saved configuration continues to apply. The main picker remains eight cards; AI / AWS remains six. Only Cornelia's video retains a contributor name.

The incident panel stacks above compute and execution history, filling the configured display rectangle and uses the booth's Cosmic Pop tokens, bundled Inter and Space Mono fonts, square controls, and shared touch keyboard styling. The optional approval note has a QWERTY keyboard with numbers and punctuation. Workflow links use the shell's contained Temporal viewer and return to the current incident.

Local mode runs real Workflows with the upstream scripted model and invocation controller. Verify investigation, approval wait, drained worker, replacement process, approval Signal, resumption, and no repeated calls. Local mode must not inherit Cloud or AWS credentials.

The single production manifest runs the Go API (`oncall-api`) and the agent's Worker as an `aws-agentcore` component (`oncall-agent`) on the `ri26-oncall` task queue. spec.aws grants the agent's exec role the Bedrock model (`BEDROCK_MODEL_ID`), and the namespace registers the `OncallPhase` search attribute. Validated against Fieldkit platform a1e2bf3b. No production stub or always-on substitute is used.

Text and spacing are compact to reduce scrolling in each half of the vertical split; controls and keyboard keys keep their touch target sizes. Bottom logo marquees use a translucent dark background so moon terrain does not obscure them.

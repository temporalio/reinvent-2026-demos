# Touch entry and mission artwork

Use a single delegated keyboard in each booth-owned demo document. Focus or touch opens it for text, email, search, telephone, URL, password, number, textarea, and editable text. Dynamically mounted React/Svelte forms use the same path. Native Photo Booth/Flight Simulator keyboards stay intact; the on-call note opts out because it already has one. Embedded Temporal views receive input assistance without changing their layout or theme.

Keep number keys above QWERTY, common email punctuation, Shift, Space, Backspace, Clear, Done, and a newline key for multiline fields. Preserve selections and maximum length, update controlled form state with native setters and bubbling events, mask password previews, and retain partial numeric decimals until completion. The drawer is fixed outside legacy body zoom, stays inside the iframe, and disappears when its field is removed. No typed values are persisted or logged.

No Roads also offers three fictional example names. Station labels automatically reveal the existing staff keyboard; PINs retain their keypad.

Use gradient line icons for tacos and loan documents. Preserve the asteroid image's intrinsic aspect ratio. Only corner reflections and half-turns are allowed, with its bottom/right cuts reflected toward the corresponding clipped card edges. Starfield crops and corner variants remain randomized.
